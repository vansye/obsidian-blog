这个项目让 Obsidian、Git 和博客各做自己擅长的事。

| 工具 | 职责 |
| --- | --- |
| Obsidian | 写作与本地知识管理 |
| Git | 内容版本与同步 |
| 博客服务 | 筛选公开内容并渲染页面 |

## 接下来想做的事

- 写三篇真正想分享的文章。
- 调整主题的字体、颜色和留白。
- 给自己留一页简洁的介绍。

框架可以被替换，内容应该能一直带走。
